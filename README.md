# 「.besをユニコード点字に変換」 based on 「UniBraille Viewer」

これは [Shunsuke Ito さんの作られた「UniBraille Viewer」](https://github.com/shunito/bes-viewer) を元に、Chat GPTで改変作成したものです。

## 何をするものか

iPhoneと点字ディスプレイを接続して、VoiceOverの点字表示機能で、サピエ図書館の.bes形式の点字図書データを読めるようにスルタメノウェブアプリです。

KGS社のブレイルメモシリーズには、「ブレイルセンス」のようなネット接続機能がないので、サピエ図書館の点字データを直接ダウンロードして読むことができません。

しかし、ブレイルメモとiPhoneの接続ができるので、iPhoneでサピエの点字データをダウンロードして読めるようにするため、これを作りました。

## iPhoneでの使い方

^1 SafariやChromeなどのブラウザで、サピエ図書館から点字データをダウンロードします。

^2 「ファイル」アプリを開き、ダウンロードした点訳図書の.zip圧縮ファイルが、「ファイル」アプリの「このiPhone内」の中、どこか、「ダウンロード」や「Chrome」フォルダに保存されているので、その圧縮ファイル「本のタイトルB7300R04130389.zip」のようなファイルを選択し、上または下フリックで、圧縮を展開します。

^3 展開すると、.zip圧縮ファイルと並んで、同じ名前のフォルダができます。そのフォルダの中にある「N0518098-001.BES」のようなファイルが、このアプリで変換できる、.besファイルです。

^4 このウェブアプリをSafariなどで開きます。アドレスは:

https://brlat.github.io/bes-to-unicode-braille

^5 ファイルを選択するためのボタンがあるので、それをタップします。

「写真ライブラリ」か、「ファイル」か、またChromeの場合は「Drive」か、選ぶ画面になるので、「ファイル」をダブルタップで開きます。

^6 「ファイル」アプリの内容が表示されるので、先ほど展開した「N0518098-001.BES」のようなファイルをさがして、それをダブルタップします。

ブラウザの表示に戻り、ユニコード点字に変換された内容がページに表示されています。

別の点字データを変換したい場合は同じように、ファイル選択のボタンを押して、変換したい.besファイルを選択します。
